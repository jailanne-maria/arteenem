# ArteENEM

Diagnóstico educacional das **quatro áreas do ENEM**. O estudante responde questões e descobre onde se destaca e onde precisa melhorar.

🔗 **Site:** https://jailanne-maria.github.io/arteenem/

## O que o app faz

- **Quiz por área:** Linguagens, Humanas, Natureza e Matemática
- **Questões estilo ENEM:** com texto de apoio e imagens para leitura e interpretação, e 5 alternativas (A–E)
- **Diagnóstico personalizado:**
  - Média geral com indicador visual
  - Desempenho por área (barras coloridas)
  - ⭐ Onde você se destaca
  - 📈 Onde precisa melhorar
  - Recomendações de estudo por área
- **Histórico:** salva o último diagnóstico no navegador

## Como usar

Abra o `index.html` no navegador — roda 100% offline, sem servidor.

1. Escolha uma área específica ou o **diagnóstico completo**
2. Responda as questões (feedback imediato com explicação)
3. Veja seu relatório ao final

## Estrutura

| Arquivo | Descrição |
|---|---|
| `index.html` | Estrutura das telas |
| `style.css` | Identidade visual (terracota/areia/verde) |
| `script.js` | Lógica do quiz e do diagnóstico |
| `questoes.js` | Banco de questões das 4 áreas |

## Tecnologias

- HTML5, CSS3 e JavaScript puro
- Fontes Outfit e Nunito
- Sem dependências externas — funciona offline
